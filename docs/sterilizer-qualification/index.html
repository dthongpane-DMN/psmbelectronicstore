5. ຄວາມປອດໄພ (Safety)

• ຫ້າມເປີດປະຕູ ຫຼື ຖອດທໍ່ ຂະນະທີ່ມີຄວາມດັນ — ກວດ gauge = 0 bar(g) ແລະ ອຸນຫະພູມ chamber <60 °C.

• PPE: ຖົງມືກັນຄວາມຮ້ອນ, ແວ່ນຕາ, ເກີບເຊບຕີ້. ລະວັງໄອນ້ຳຮ້ອນ ແລະ ນ້ຳ condensate.
• ຫ້າມ bypass interlock ຫຼື safety valve ເວັ້ນແຕ່ໃນການທົດສອບທີ່ໄດ້ຮັບອະນຸຍາດ.

7. ຂັ້ນຕອນ (Procedure)

7.1 ການທົດສອບປະຈຳວັນ (Operator)

  1. ກວດ utilities: ຄວາມດັນ clean steam ____ bar(g), ອາກາດອັດ ____ bar(g), ນ້ຳເຢັນ, ໄຟຟ້າ. ບັນທຶກໃນ logbook.
  2. ເຮັດຄວາມສະອາດ drain strainer; ກວດ door gasket ດ້ວຍຕາ (ບໍ່ມີຮອຍແຕກ/ຜິດຮູບ).
  3. ແລ່ນ warm-up cycle (chamber ເປົ່າ).
  4. ແລ່ນ Vacuum leak test → ເກນ ≤1.3 mbar/min. ບໍ່ຜ່ານ → ຢຸດໃຊ້, ແຈ້ງ Engineering.
  5. ວາງ BD test pack ຢູ່ ກາງ chamber ດ້ານລຸ່ມ ໃກ້ປະຕູ/drain (ຕາມຜູ້ຜະລິດ) ໃນ chamber ເປົ່າ → ແລ່ນ BD cycle (134 °C, 3.5 min).
  6. ອ່ານຜົນ: ປ່ຽນສີສະໝ່ຳສະເໝີ = Pass. ບໍ່ສະໝ່ຳສະເໝີ = Fail → ເຮັດຊ້ຳ 1 ຄັ້ງ; ຖ້າບໍ່ຜ່ານອີກ → ຢຸດເຄື່ອງ, ເປີດ Deviation F-04.
  7. ຕິດ BD sheet + printout ໃນ logbook, ລົງລາຍເຊັນ ແລະ ວັນທີ.

7.2 BI test ປະຈຳອາທິດ

  1. ໃສ່ BI ໃນ PCD, ວາງທີ່ cold spot ທີ່ກຳນົດໃນ PQ ຂອງ load ປົກກະຕິ.
  2. ຫຼັງ cycle: ສົ່ງ BI ໃຫ້ QC ພ້ອມ positive control (ລັອດດຽວກັນ ບໍ່ຜ່ານ cycle). ບົ່ມ 55–60 °C ຕາມເວລາທີ່ຜູ້ຜະລິດ BI ກຳນົດ.
  3. BI ເຕີບໂຕ (positive) → ກັກ (quarantine) ທຸກ load ຕັ້ງແຕ່ BI negative ຄັ້ງສຸດທ້າຍ, ເປີດ Deviation, ປະເມີນ recall ຕາມ AAMI ST79.

7.3 PM ຕາມແຜນ (Technician)

  1. ຮັບ Work Order; ປະສານ Production ເພື່ອຢຸດເຄື່ອງ; ກະກຽມ F-01, ອາໄຫຼ່, ເຄື່ອງມືທີ່ calibrate ແລ້ວ.
  2. Shut down → ລະບາຍຄວາມດັນ → ລໍໃຫ້ເຢັນ → LOTO.
  3. ປະຕິບັດລາຍການໃນ F-01 ຕາມຄວາມຖີ່ (ພາກ 4.3). ບັນທຶກຄ່າວັດ ທັນທີ ດ້ວຍປາກກາໝຶກ (ALCOA+); ແກ້ໄຂແບບຂີດເສັ້ນດຽວ + ລາຍເຊັນ + ວັນທີ + ເຫດຜົນ.
  4. Calibration: ປຽບທຽບກັບ reference ທີ່ 3 ຈຸດ; ຖ້າເກີນເກນ (ອຸນຫະພູມ ±0.5 °C, ຄວາມດັນ ±1 % FS ຫຼື ຕາມ URS) → ປັບ (adjust) ແລະ ບັນທຶກ as found / as left; ຖ້າ as found ເກີນເກນ → ເປີດ Deviation ເພື່ອປະເມີນຜົນກະທົບຕໍ່ batch ທີ່ຜ່ານມາ.
  5. ຖອດ LOTO; ແລ່ນ post-PM test: leak test + BD (+ BI 3 runs ຖ້າປ່ຽນ critical part).
  6. ສົ່ງ F-01 ໃຫ້ Supervisor ແລະ QA ທົບທວນ; QA ອະນຸມັດ → ຕິດປ້າຍ "Ready for use".

7.4 ການສ້ອມແປງ (CM) ແລະ Change control

  1. ທຸກຄວາມເສຍຫາຍ → ບັນທຶກ Work Order CM; ການປ່ຽນແບບ like-for-like → ທົດສອບຫຼັງສ້ອມຕາມພາກ 4.3.
  2. ການປ່ຽນທີ່ບໍ່ແມ່ນ like-for-like (software, cycle parameter, piping, sensor type) → ຕ້ອງຜ່ານ Change Control ແລະ QA ກຳນົດຂອບເຂດ requalification ກ່ອນເລີ່ມ.

8. ບັນທຶກ (Records)

Logbook ເຄື່ອງ, F-01 PM checklist, calibration certificates, BD sheets, BI results, cycle printouts/electronic records (ສຳຮອງຂໍ້ມູນ, audit trail ຕາມ Annex 11), Deviation F-04. ເກັບຮັກສາ ≥1 ປີຫຼັງວັນໝົດອາຍຸຂອງ batch ທີ່ກ່ຽວຂ້ອງ ຫຼື ຕາມນະໂຍບາຍໂຮງງານ (ຢ່າງໜ້ອຍ 5 ປີ).

A. ຈຸດປະສົງ

ພິສູດວ່າ cycle ທີ່ກຳນົດ ໃຫ້ຜົນສະໝ່ຳສະເໝີ ກັບ load ຈິງ ແລະ ບັນລຸ SAL ≤10-6 ໃນທຸກຈຸດຂອງ load ລວມທັງ cold spot (ISO 17665:2024 — PQ; PIC/S Annex 1 §8.33–8.50; WHO TRS 1044 Annex 2).

B. ວິທີການ (Method)

  1. ຈັດ load ຕາມແຜນຜັງທີ່ອະນຸມັດ (ຊະນິດ, ຈຳນວນ, ການຫຸ້ມຫໍ່ ISO 11607, ຕຳແໜ່ງ).
  2. ໃສ່ thermocouples ≥10 ຈຸດ ພາຍໃນ ສິ່ງຂອງ (ຈຸດທີ່ຮ້ອນຊ້າທີ່ສຸດ: ກາງ pack, ພາຍໃນທໍ່, ຂວດນ້ຳ) + 1 ໃກ້ drain probe.
  3. ວາງ BI (≥106, D121 ≥1.5 min) ຕິດກັບ thermocouple ແຕ່ລະຈຸດ + CI Type 5/6.
  4. ແລ່ນ 3 runs ຕິດຕໍ່ກັນ ທີ່ສຳເລັດ ຕໍ່ load pattern. ຫ້າມປັບ parameter ລະຫວ່າງ runs.
  5. ຊັ່ງນ້ຳໜັກ load ກ່ອນ/ຫຼັງ ເພື່ອກວດຄວາມແຫ້ງ; ກວດ wet pack ດ້ວຍຕາ.
  6. ສົ່ງ BI ໃຫ້ QC ບົ່ມ ພ້ອມ positive ແລະ negative controls; ຄິດໄລ່ F0 = Σ 10(T−121.1)/10 · Δt (min).
