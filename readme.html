2 · ເອົາຂຶ້ນເວັບ Put it online

ແອັບຕ້ອງເປີດຜ່ານ https:// ຈຶ່ງຈະຕິດຕັ້ງໄດ້ — ເປີດຈາກໄຟລ໌ໃນເຄື່ອງ (file://) ຈະຕິດຕັ້ງບໍ່ໄດ້. The app must be served over https:// to be installable — opening the file directly will not work.

ວິທີ ກ · Netlify Drop — ງ່າຍທີ່ສຸດ, ບໍ່ຕ້ອງໃຊ້ຄຳສັ່ງ / easiest, no command line

  1. ເປີດ app.netlify.com/drop
  2. ລາກ ໂຟລເດີທັງໝົດ (ບໍ່ແມ່ນໄຟລ໌ zip) ໄປວາງໃນໜ້ານັ້ນ
  3. ຈະໄດ້ລິ້ງ https ທັນທີ — ສ້າງບັນຊີຟຣີເພື່ອໃຫ້ລິ້ງຢູ່ຖາວອນ ແລະ ປ່ຽນຊື່ໄດ້

ວິທີ ຂ · Vercel

ຈາກໃນໂຟລເດີນີ້ ແລ່ນຄຳສັ່ງ: Run from inside this folder:

npx vercel deploy --prod --yes
⚠ ໃນບັນຊີ Vercel ຂອງເຈົ້າມີ project ຊື່ cbf-stock ທີ່ອັບໂຫຼດບໍ່ຄົບ ໃຊ້ບໍ່ໄດ້ — ໃຫ້ລຶບຖິ້ມ ຫຼື deploy ທັບ.
A half-uploaded cbf-stock project exists in your Vercel account — redeploy over it with the command above, or delete it.

ວິທີ ຄ · Server ຂອງໂຮງງານ — ຂໍ້ມູນບໍ່ອອກນອກ / on-premise

ເອົາໄຟລ໌ທັງໝົດໃສ່ web server ໃດກໍໄດ້ (nginx, Apache, IIS). ຕ້ອງເປັນ https ຫຼື localhost. Copy the files to any web server. https or localhost is required.

3 · ສ້າງຖານຂໍ້ມູນກາງ Create the shared database

ຂັ້ນຕອນນີ້ເຮັດ ເທື່ອດຽວ — ເປັນສິ່ງທີ່ເຮັດໃຫ້ທຸກເຄື່ອງເຫັນຂໍ້ມູນດຽວກັນ. Do this once — it is what lets every device see the same data.

  1. ສ້າງບັນຊີຟຣີທີ່ supabase.com → New project (ເລືອກ region Singapore ຈະໄວທີ່ສຸດສຳລັບລາວ)
  2. ໄປ SQL Editor → ວາງເນື້ອໃນຂອງ supabase-setup.sql → ກົດ Run
  3. ໄປ Settings → API → ສຳເນົາ Project URL ແລະ anon public key
  4. ເປີດແອັບ → ໜ້າ ຊິງຄ໌ & ຕິດຕັ້ງ → ວາງສອງຄ່ານັ້ນ → ບັນທຶກ & ທົດສອບ

ຖ້າຂຶ້ນ ✓ ຊິງຄ໌ເປີດຢູ່ ແປວ່າສຳເລັດ. “Synced” means it worked.

4 · ໃຫ້ພະນັກງານໃຊ້ນຳ Add your team

ໃນໜ້າ ຊິງຄ໌ & ຕິດຕັ້ງ ຈະມີ ລິ້ງຕັ້ງຄ່າ ແລະ ປຸ່ມ QR. ພະນັກງານເປີດລິ້ງນັ້ນ (ຫຼື ສະແກນ QR) ເທື່ອດຽວ — ເຄື່ອງຂອງລາວຈະເຊື່ອມກັບຖານຂໍ້ມູນດຽວກັນທັນທີ ໂດຍບໍ່ຕ້ອງພິມ key ເອງ.

Open “Sync & Install”, copy the setup link or show the QR code. A colleague opens it once and their device is connected — nothing to type.

⚠ ລະບົບນີ້ ບໍ່ມີການ login ຕາມທີ່ເຈົ້າເລືອກ — ໃຜມີລິ້ງນັ້ນກໍເຂົ້າເຖິງ ແລະ ແກ້ຂໍ້ມູນໄດ້. ຢ່າສົ່ງໃຫ້ຄົນນອກທີມ ແລະ ຢ່າໂພສໃນກຸ່ມສາທາລະນະ.
There is no login, as requested. Anyone with the link can read and edit. Keep it inside the team.

5 · ຕິດຕັ້ງເປັນແອັບ Install as an app

ເຄື່ອງ / Deviceວິທີ / How
PC — Chrome / Edgeເປີດລິ້ງ → ກົດໄອຄອນ ຕິດຕັ້ງ (⊞) ທາງຂວາຂອງຊ່ອງ address → InstallOr menu → Install app. It then opens in its own window like a normal program.
AndroidChrome → ເມນູ ⋮ → ຕິດຕັ້ງແອັບ / Add to Home screen
iPhone / iPadຕ້ອງໃຊ້ Safari → ປຸ່ມ Share ⤴ → Add to Home ScreenChrome on iOS cannot install web apps — use Safari.

ຕິດຕັ້ງແລ້ວຈະມີໄອຄອນຢູ່ໜ້າຈໍ ແລະ ເປີດໃຊ້ໄດ້ເຖິງແມ່ນເນັດຂາດ — ຂໍ້ມູນທີ່ບັນທຶກຕອນເນັດຂາດຈະສົ່ງຂຶ້ນເອງເມື່ອເນັດກັບມາ. Once installed it works offline; anything saved offline is sent up automatically when the connection returns.

6 · ນຳເຂົ້າລາຍການສີນຄ້າຈາກ Excel Import products from Excel

ໜ້າ ລາຍການສີນຄ້າ → ນຳເຂົ້າຈາກ Excel. ຮັບໄດ້ທັງ .xlsx, .xls ແລະ .csv.

  1. ເລືອກໄຟລ໌ → ລະບົບຈະຈັບຄູ່ຫົວຄໍລຳໃຫ້ເອງ (ລາວ ຫຼື ອັງກິດ)
  2. ກວດເບິ່ງການຈັບຄູ່ — ຄໍລຳໃດບໍ່ໃຊ້ ເລືອກ “ບໍ່ໃຊ້” ໄດ້
  3. ເບິ່ງຕົວຢ່າງ (ໃໝ່ / ອັບເດດ) ແລ້ວກົດ ນຳເຂົ້າ

ຖ້າມີຄໍລຳ ຈຳນວນ ນຳ, ລະບົບຈະສ້າງສະຕັອກເປີດໃຫ້ເລີຍ ພ້ອມ Lot, ວັນໝົດອາຍຸ ແລະ ສາງ. ລາຍການທີ່ ລະຫັດ ຊ້ຳກັບຂອງເກົ່າຈະຖືກອັບເດດ ບໍ່ແມ່ນສ້າງໃໝ່.

A quantity column also creates the opening stock, with its lot, expiry and warehouse. Rows whose code already exists update that product instead of duplicating it.

ຕ້ອງມີຢ່າງໜ້ອຍ ລະຫັດ ຫຼື ຊື່ສີນຄ້າ — ນອກນັ້ນເລືອກໄດ້. ໃຊ້ pbsm-import-template.csv ເປັນຕົວຢ່າງ.

6b · ໃສ່ໂລໂກ້ຮ້ານ Add your shop logo

ໜ້າ ຕັ້ງຄ່າ → ຫ້ອງ ໂລໂກ້ຮ້ານ → ເລືອກຮູບ (PNG ຫຼື JPG, ພື້ນຫຼັງໃສກໍໄດ້). ໂລໂກ້ຈະໄປປາກົດ ໜ້າຊື່ຮ້ານ ໃນແຖບຊ້າຍມື ແລະ ຢູ່ ຫົວໃບບິນຂາຍ, ໃບສະເໜີລາຄາ, ໃບຮັບເງິນ ແລະ ລາຍງານ ທຸກໃບ.

Settings → Shop logo → Choose image. It appears beside the shop name in the sidebar and at the top of every printed document.

ຮູບຈະຖືກຫຍໍ້ໃຫ້ອັດຕະໂນມັດ ແລະ ເກັບໄວ້ນຳຖານຂໍ້ມູນ — ຕັ້ງເທື່ອດຽວ ທຸກເຄື່ອງທີ່ແຊຂໍ້ມູນນຳກັນຈະເຫັນຄືກັນ. ປ່ຽນ ຫຼື ລຶບອອກຕອນໃດກໍໄດ້ດ້ວຍປຸ່ມ ລຶບໂລໂກ້. The image is resized automatically and stored with the data, so every device that shares the database picks it up.

ໂລໂກ້ນີ້ໃຊ້ໃນແອັບ ແລະ ໃນເອກະສານທີ່ພິມ. ສ່ວນ ໄອຄອນຕອນຕິດຕັ້ງແອັບ (ທີ່ຂຶ້ນໜ້າຈໍມືຖື) ຍັງເປັນ “PB” ສີຂຽວ — ຖ້າຢາກໃຫ້ເປັນໂລໂກ້ຮ້ານນຳ ສົ່ງໄຟລ໌ໂລໂກ້ມາໃຫ້ຂ້ອຍ ແລ້ວຂ້ອຍຈະສ້າງ icon-192 / icon-512 ໃໝ່ໃຫ້.
The installed app icon is still the green “PB” mark — send me the logo file and I will rebuild the icon PNGs from it.

7 · ໃບຮັບເງິນ ແລະ ຫຼາຍສາງ Receipts and warehouses

ໃບຮັບເງິນ Receipts

ໜ້າ ໃບຮັບເງິນ ສະແດງບິນທີ່ຍັງຄ້າງຊຳລະທັງໝົດ. ກົດ ຮັບເງິນ ໃສ່ບິນໃດກໍໄດ້ → ເລືອກບິນ (ຮັບເງິນເທື່ອດຽວຫຼາຍບິນໄດ້) → ໃສ່ຈຳນວນ → ບັນທຶກ ແລ້ວພິມໄດ້ເລີຍ. ຈຳນວນເງິນຈະຂຽນເປັນຕົວໜັງສືລາວໃນໃບຮັບເງິນໃຫ້ອັດຕະໂນມັດ. ບິນຈະຂຶ້ນສະຖານະ ຊຳລະບາງສ່ວນ ຫຼື ຊຳລະຄົບ ເອງ.

One receipt can settle several invoices. The Lao amount-in-words line is generated automatically, and each invoice's paid / partial / unpaid status follows from the receipts.

ຫຼາຍສາງ Warehouses

ໜ້າ ສາງ & ໂອນຍ້າຍ → ສ້າງສາງໄດ້ຕາມຕ້ອງການ. ຮັບເຂົ້າສະຕັອກຕ້ອງເລືອກສາງ, ແລະ ໃບບິນຂາຍກໍເລືອກສາງທີ່ຈະຕັດອອກ — ລະບົບຈະຕັດແບບ FEFO (Lot ໝົດອາຍຸກ່ອນ ອອກກ່ອນ) ສະເພາະໃນສາງນັ້ນ. ການ ໂອນຍ້າຍ ຈະຍ້າຍ Lot ພ້ອມວັນໝົດອາຍຸ ແລະ ຕົ້ນທຶນ ໄປສາງປາຍທາງ ແລະ ເກັບປະຫວັດໄວ້.

Stock is deducted FEFO within the chosen warehouse. Transfers carry the lot number, expiry and cost across and are kept in a transfer history.

8 · ສຳຮອງຂໍ້ມູນ Backups

Supabase ສຳຮອງໃຫ້ເອງຢູ່ແລ້ວ, ແຕ່ໜ້າ ຊິງຄ໌ & ຕິດຕັ້ງ ຍັງມີ ສົ່ງອອກໄຟລ໌ສຳຮອງ (JSON) ແລະ ກູ້ຄືນຈາກໄຟລ໌ ນຳ — ແນະນຳໃຫ້ດາວໂຫຼດເກັບໄວ້ເດືອນລະເທື່ອ. ນອກນັ້ນ ໜ້າ ຕັ້ງຄ່າ ແລະ ສະຫຼຸບປະຈຳເດືອນ ສົ່ງອອກເປັນ CSV ໄດ້ ສຳລັບເອົາໄປໃຊ້ຕໍ່ໃນ Excel.

Monthly JSON backup is recommended. Stock and monthly report also export to CSV for Excel.
